Pull Customer Master API

Overview

This API retrieves all details about customer master for a given company. It is intended for third-party systems that need to pull customer master records from the ERP. Only customers that are active, approved, and assigned for the specified company are returned.

The category parameter is optional; when provided, it must be an array of category descriptions (e.g. ["General", "POS"]). Only customers in any of those categories are returned.

Pagination: If page or per_page is sent, the response is paginated (default per_page: 10, maximum: 50). If neither page nor per_page is sent, all matching customers are returned in a single array (no pagination).

The response includes customer header data, GL account details (receivable, unbilled, advance), contact details (multiple per customer), and currency details (multiple per customer). Credit limit is returned with the company's reporting currency in the key (e.g. creditLimit(OMR)).

Endpoint
POST /api/v1/customer_master
Headers
Header Type Required Description
Authorization string Yes API key for authentication (format: {{third party system code}} {{api token}})
Content-Type string Yes application/json
Accept string Yes application/json

Request Body
Parameter Type Required Description
category array Optional Array of customer category descriptions (e.g. ["General", "POS"]). If provided, only customers in any of these categories are returned. Each value must match an existing categoryDescription in the system.
page integer No Page number for pagination (default: 1, minimum: 1). If neither page nor per_page is sent, all records are returned without pagination.
per_page integer No Number of items per page (default: 10, minimum: 1, maximum: 50). If neither page nor per_page is sent, all records are returned without pagination.

Pagination Response Object
Field Type Description
current_page integer Current page number
data array Array of customer objects for the current page
first_page_url string URL to the first page
from integer Starting record number for current page
last_page integer Last page number
last_page_url string URL to the last page
links array Array of link objects for pagination navigation (Previous, page numbers, Next). See Link Object below.
next_page_url string URL to the next page (null if on last page)
path string Base path for pagination URLs
per_page integer Number of items per page
prev_page_url string URL to the previous page (null if on first page)
to integer Ending record number for current page
total integer Total number of records across all pages

Link Object (within links array)
Field Type Description
url string URL for this link (null for Previous when on first page, or Next when on last page)
label string Display label (e.g. "« Previous", "1", "2", "Next »")
page integer Page number for this link (null for Previous/Next when not applicable)
active boolean True if this link is the current page

Data Structure
Customer Object
Field Type Description
primaryCode string Customer code
secondaryCode string Customer short code
customerName string Customer name
reportTitle string Report title
category string Customer category description
interCompanyYesNo string Inter-company flag (Yes/No)
country string Country name
city string City
creditLimit(OMR) number Credit limit; key suffix is company reporting currency (e.g. OMR, USD)
creditPeriod number Credit period
registrationNumber string Customer registration number
registrationExpiryDate string Registration expiry date (format: YYYY-MM-DD)
isActive string Is active (Yes/No)
vatEligible string VAT eligible (Yes/No)
vatNumber string VAT number
vatPercentage number VAT percentage
glDetails object GL account details (see GL Details Object). Values may be "code - description".
contactDetails array Array of contact objects (see Contact Object). Multiple contacts per customer.
currencyDetails array Array of currency objects (see Currency Object). Multiple currencies per customer.

GL Details Object
Field Type Description
receivableAccount string Receivable account (code - description)
unbilledAccount string Unbilled account (code - description)
advanceAccount string Advance account (code - description)

Contact Object
Field Type Description
contactType string Contact type description (e.g. Primary)
contactPersonName string Contact person name
telephone string Telephone number
fax string Fax number
email string Email address
isDefault string Is default contact (Yes/No)

Currency Object
Field Type Description
currencyName string Currency name
isDefault string Is default currency (Yes/No)
isAssigned string Is assigned (Yes/No)
